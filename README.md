# enact-agent releases

**Deprecated.** The Enact Agent distribution is published from
[adl-tan-theta/enact-agent](https://github.com/adl-tan-theta/enact-agent)
releases, under the `enact-agent-v<version>` tag. That is where the
installers and the Homebrew tap point, and where the checksums live.

This repository holds the earlier `enactrs` releases (version 0.0.4,
August 2026). Nothing publishes to it any more, and no workflow in the
fork references it. It stays here for the installs that still use those
binaries.
